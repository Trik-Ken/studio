# **App Name**: B2B Commerce Connect

## Core Features:

- Product Discovery: Explore page featuring a product listing view with search functionality.
- Product Details: Product detail page with carousel, description, specifications, warranty & returns, company name, and unit-wise price.
- Company Profile: Company profile page displaying company details and listed products with a chat button.
- Chat List: Chat page listing companies the user has chatted with, including search functionality.
- Direct Chat: One-on-one chat screen with company name, call button, info button, and chat features.
- Profile Management: Profile page showing logged-in company's profile, details, and listed products, with a settings button.
- Settings: Settings page for editing profile, security options, and help & support.

## Style Guidelines:

- Primary color: A muted blue (#6699CC), conveying trust and professionalism.
- Background color: A very light blue (#F0F8FF), almost white, maintaining a clean interface.
- Accent color: A desaturated violet (#8A2BE2), adds visual interest to key actions.
- Clean and professional typography choices for readability.
- Consistent and clear icons to represent actions and categories.
- Bottom navigation bar for easy access to main sections.
- Subtle transitions between pages with gesture support.
